# Sistem KMKP RSUD Merauke
Pelaporan mutu dan insiden keselamatan pasien.

## Unggah ke GitHub Pages
Unggah `index.html`, `logo.png`, dan `.nojekyll` ke root repositori, lalu aktifkan Settings > Pages.

## Backend (Google Apps Script)
Folder `apps-script/` berisi file backend (code.gs, api.gs, mutu.gs, komite.gs) dan Index.html versi Apps Script. Tidak perlu diunggah ke GitHub Pages.
